# Cut numeric variables into intervals

Wrapper for cut() with simplified labels and automatic conversion to
factor based on most frequent levels

## Usage

``` r
cutR(
  data,
  vars,
  seq.list,
  name.list = list(),
  name.pattern = NULL,
  simplify = T,
  digits = 0,
  dt = F
)
```

## Arguments

- data:

  dataframe. Works with piping.

- vars:

  Vector of vars which should be cut

- seq.list:

  List of the split patterns for each var. E.g. list("v1" = seq(0,10),
  "v2" = round(quantile(df %\>% pull(age), seq(0,1,0.1)),0)).\\ Can be
  specified using only "median", "quantile", "quartile" etc which will
  be applied to all vars

- name.list:

  list of names for new variables in the format: list("new" = "old").
  Names can also be provided as a vector of same length as vars.

- name.pattern:

  naming pattern that should automatically be pasted on the end of all
  the specified variable names in "vars".

- simplify:

  whether date intervals should be simplified

- digits:

  number of digits for label formatting

- dt:

  whether a data.table should be returned (default = F)

## Value

The inputted dataframe with the cut variables
